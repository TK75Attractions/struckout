# 2026-10-14 の KYV45 2 台 (120fps 版) のテストのメモ

KYV45 の 2 台に 120fps 版 (`com.taichi765.struckoutCameraApp.highspeed`) を入れ、ball_tracker に USB (adb reverse)
でつないで投球した。ball_tracker と同時に、2 台の画面を `adb shell screenrecord` で録画した。
着弾の正解は、別の角度から別のスマホで撮った動画にある (このフォルダには入っていない)。

**結果: 投球の時間帯には、どちらのカメラからもフレームが届いておらず、着弾は 0 件だった。**
2 台とも、画面が自動で消えて (画面消灯までの時間が 60 秒) カメラが止まっていた (下の「何が起きたか」)。

## 構成

| | `166810122536` (Android 10) | `166810131208` (Android 9) |
|---|---|---|
| camera_id (1652 の回) | 0 | 1 |
| 位置 x, y, z (m) | 0.075, 1.08, 1.258 (右) | 0.075, 0.12, 1.2587 (左) |
| 回転 x, y, z (度) | 131.814, -1.825, -150.017 | 137.365, -1.534, -31.474 |
| 画像 | 640×360、120fps、焦点距離 482.19px | 同じ |
| 行ごとの露光のずれ / 露光時間 | 8.333ms / 8.0ms | 同じ |
| 時刻合わせ | `synced=true`、往復 3〜6ms | `synced=true`、往復 4〜5ms |
| 端末の時計 (17:06 に PC と比べた) | PC より約 42 秒遅れ | PC より約 100 秒遅れ |

- 2 台とも機種名が同じ (`KYV45`) なので、ball_tracker のログだけでは camera_id と端末を区別できない。
  上の対応は、フレームが届いた時間と、端末のログで画面が消えた時刻から決めた。
- 2 台とも `timestamp_source: Unknown` (KYV45 はセンサー時刻の時計の種類を知らせない)。
- 端末の時計は PC より遅れているので、logcat の時刻は上の分だけ足して PC の時刻に直す。
- ball_tracker のバイナリは 10/12 19:45 のビルド。アプリは `f0a4499` 時点のソースからビルドしたもの。

## 何が起きたか

時刻は PC の時刻 (JST)。

| 時刻 | 起きたこと |
|---|---|
| 16:14 | ball_tracker を起動 (`tracker_1614.log`)。どの端末からも接続がなかった |
| 16:39〜16:40 | 2 台で 120fps 版を起動して撮影を始めたところ、2 台とも落ちた。USB がつながり直して adb reverse が消え、未接続のまま検出したため (`../2026-10-14_two-phones/issues.md` の 2 と 12) |
| 16:52:05 | ball_tracker と画面の録画を起動 (`tracker_1652.log`、`scripts/run-experiment.ps1`) |
| 16:53:32 | `166810122536` が接続 (camera_id 0) |
| 16:53:52〜16:54:24 | camera_id 0 からフレームが届く (490 フレーム) |
| 16:54:22 | `166810131208` が接続 (camera_id 1)。位置は 0 のままで、16:57:10 に入力した値に更新された |
| 16:54:40 ごろ | `166810122536` の画面が消え (`Going to sleep due to timeout`)、カメラが閉じる |
| 16:57:12〜16:57:58 | camera_id 1 からフレームが届く (577 フレーム) |
| 16:58:09 ごろ | `166810131208` の画面が消え (`Going to sleep due to screen timeout`)、カメラが閉じる |
| 16:58〜17:01 | 投球 (この間、どちらのカメラも止まっていた) |
| 17:01:1x | ball_tracker を Ctrl+C で止める。接続が切れて、2 台ともアプリが落ちた (issues.md の 1) |

- 画面消灯までの時間は 2 台とも 60 秒 (`settings get system screen_off_timeout` = 60000)。
  画面が消えるとアプリが止まり、カメラも閉じる (`CameraService: disconnect`)。
- 画面が消えても、ball_tracker との接続は切れなかった (ログに `camera disconnected` がない)。
  そのため、ball_tracker の画面からは止まったことがわからなかった。

画面の録画は、アプリが表示している画像を録ったもので、検出があるときで最大 10fps、ないときは 2fps に間引かれている。
検出した枠 (赤) と、範囲の外で捨てた検出 (灰) が描き込まれている。画面が変わらないあいだはフレームが作られない。

## 次のテストで直すこと

- 撮影中に画面が消えないようにする。今は端末の設定で、画面消灯までの時間を長くするしかない
  (アプリで画面を点けたままにする修正は `../2026-10-14_two-phones/issues.md` の 13)。
- 投球を始める前と途中で、2 台の画面が点いていて、カメラ画面の fps が出ていることを確かめる。ball_tracker の
  `camera clock` は検出があったときしか出ないので、出ていなくても止まったとは限らない。
